# Sanctify Tower Defense

A Roblox fantasy tower defense game set in a sacred forest sanctuary.

- `CLAUDE.md` — AI development guide (workflow, architecture, rules, current status)
- `docs/DESIGN.md` — game design (Decided vs Idea)

## Setup
1. Install Rojo (e.g. via Rokit: `rokit add rojo-rbx/rojo`)
2. `rojo serve`, then connect with the Rojo plugin in Roblox Studio
3. The map, path waypoints and sanctuary live in the place file (`*.rbxl`), which is not tracked in git — back it up separately
